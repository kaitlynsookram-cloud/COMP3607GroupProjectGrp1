BlueJ Analytics Extension
For this project, we made a BlueJ extension that keeps track of what students do while coding. It records things like typing, changes made to classes and methods, compiling and running programs. We used Java 17, BlueJ 6.0.1 and Maven, but Java 21 can also work if it's set up properly. To build the project and run the tests, use mvn clean verify in IntelliJ. We used JUnit 5 for testing and JaCoCo for code coverage. All 87 tests passed and we reached the required 75% coverage. To try out the extension, copy the JAR file into BlueJ's extensions folder and restart BlueJ. The extension saves the activity in analytics-session.json and also generates a PDF report. The BlueJ JAR path in pom.xml might need to be changed depending on where BlueJ is installed.
