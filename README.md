BlueJ Analytics Extension
This project is a BlueJ extension that records what a student does while coding, like typing, making changes to classes and methods, compiling code and running programs. The project uses Java 17, BlueJ 6.0.1 and Maven. Java 21 can also be used if it is set up correctly. To build the project and run the tests, use `mvn clean verify` in IntelliJ. I used JUnit 5 for testing and JaCoCo to check code coverage. All 87 tests passed, and the project met the 75% coverage requirement. To use the extension in BlueJ, copy the JAR file from the `target` folder into BlueJ's extensions folder and restart BlueJ. The information collected is saved in `analytics-session.json`, and a PDF report is also created to show the results. The BlueJ JAR path in `pom.xml` may need to be changed depending on where BlueJ is installed.
